# Project Structure

The split exists so agents can instantly tell the runtime surface from
tooling and from the local-only reference corpus. Engineering rules live in
[../AGENTS.md](../AGENTS.md) (its §0 TH08 overlay is authoritative); this
file is the map.

## Runtime surface (what the browser loads)

- `index.html` — static entry. Loads `dist/th08.js`; must keep working when
  opened directly from disk (no dev server required).
- `src/th08.css` — page shell and canvas scaling.
- `dist/th08.js` — esbuild IIFE bundle of `src/main.ts` (**generated** by
  `npm run build`; never hand-edited, never committed).
- `assets/th08-img/` — textures extracted from the original TH08 ANM files.
- `assets/audio/th08/` — BGM Oggs sliced from the original stream with the
  `thbgm.fmt` loop table (`scripts/split-th08-bgm.mjs`).
- `assets/sfx/th08/` — original `se_*.wav` sound effects.

Browser code must not read from `reference/`, `tests/`, `scripts/`,
`docs/`, or `node_modules/`.

## Source tree (`src/`)

- `main.ts` — boot and scene wiring: `Th08MenuFlow` (title/difficulty/team)
  ↔ `StageScene`, plus the `window.__TH08_TEST__` deterministic test hook
  (`?test=1`; `?menu=1` forces the menu flow; probes accept `?difficulty=`,
  `?power=`, `?dialogue=`, `?paused=`, `?pace=`).
- `core/` — `loop.ts` fixed-step 60 FPS loop, `input.ts` keyboard state
  with pressed-edge tracking, `rng.ts` the original 16-bit RNG port,
  `pacing.ts` frame-delivery policy, `replay-input.ts`, `latency.ts`.
- `formats/` — TH08 format parsers: `ecl.ts` (v8 container + timeline v2),
  `anm.ts` (v3 entries and ops), `std.ts`, `msg.ts` (XOR-0x77 payloads),
  `sht.ts` (56-byte headers/records), `rpy.ts` (T8RP v6).
- `data/th08-data.ts` — embedded original binaries (stage 1 ECL/STD/MSG/
  enemy ANMs, SHT, BGM loop table). Generated by `scripts/generate-th08-data.mjs`.
- `game/` — `stage-scene.ts` (the play scene: managers, collision, HUD,
  draw), `eclvm.ts` (the ECL interpreter), `player.ts`, and the TH08
  modules: `th08-title-scene.ts` / `th08-menu*.ts` (menus), `th08-state.ts`
  (score/gauge/clock run state), `th08-dialogue.ts`, `th08-declaration.ts`
  (bomb spell-card cut-in), `th08-border-bombs.ts`, `th08-option-shot.ts`,
  `th08-item-spawn.ts`, `th08-hud-layout.ts`, `th08-player-motion.ts`.
- `testkit/replay-entry.ts` — the Node harness bundle entry (ships nothing).

## Tooling (`scripts/`)

- `replay-verify-th08.mjs` — the Stage 1 Lunatic convergence oracle over
  `tests/replays/th8_udLy01.rpy`.
- `dev-shot.mjs` / `dev-menu.mjs` / `pixel-report.mjs` — headless browser
  probes (drive `window.__TH08_TEST__`).
- `verify.mjs` — check/build/test + replay + pixel orchestrator.
- `generate-th08-data.mjs`, `extract-th08-assets.mjs`, `split-th08-bgm.mjs`
  — rebuild the embedded data and asset dirs from the local reference corpus.
- `native-trace.mjs` — wine+winedbg PRE-trace procedure (needs a host that
  can boot Th08.exe under a debugger).
- `prepare-pages.mjs` / `deploy-pages.mjs` — the static Pages tree.

## Tests (`tests/`)

`th08-*.test.mjs` (behavior regressions), `engine-*.test.mjs` (shared
engine pins: pacing, float32 angle wrap, STD renderer math, LZSS), plus the
committed replay fixture `tests/replays/th8_udLy01.rpy`. TH07-era tests and
the golden digest were removed with the TH07 path.

## Local-only (never committed)

`reference/` (the original corpus and decompiles), `replay/` (third-party
recordings), `tmp/`, `dist/`, `score.dat`, `th08.cfg`.
